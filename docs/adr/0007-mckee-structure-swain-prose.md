# ADR 0007: McKee owns story structure; Swain and MRU own prose craft

Status: accepted

Story structure follows Robert McKee: Value Axis, Charge, Value Turn, Gap, and
the Beat / Scene / Sequence / Act / Story levels, all planned before prose is
written. Swain's scene/sequel and motivation-reaction units stay, but only as
paragraph-level writing guidance for how a planned Beat is rendered. Beat types
are McKee's action, reaction and turn; Swain categories (goal, conflict,
disaster, and so on) remain optional labels. Skills and checks use McKee terms
for structure so agents never receive two competing structural vocabularies.

This applies to projects created through `new-book` after this change; existing
projects keep their current behaviour and cannot opt in.
